One original dad joke, written to be told out loud at the dinner table. A small Python program writes it to `/output/entry.txt` — deterministic, no network, no input, no dependencies beyond the standard library.

> I told my son the moon throws shade at the sun every few years. He said, 'Dad, that's an eclipse.' I said, 'No, son, that's just the moon being shady.'

## Run it

```sh
python3 main.py
```

It writes the joke to `/output/entry.txt` and prints it to stdout.
